# Placeholder para Hero

Este archivo debe ser reemplazado con la foto principal del hero.

## Especificaciones

- **Tamaño recomendado**: 1920x1080 px (landscape)
- **Formato**: JPG
- **Compresión**: Máx 800KB
- **Orientación**: Landscape (horizontal)

## Tips

1. Usar una foto donde se vean los novios
2. Evitar texto superpuesto
3. Preferir fondos simples/blur para mejor legibilidad del texto del hero
4. Optimizar con [Squoosh.app](https://squoosh.app)

## Ejemplo de URL para placeholder (Unsplash)

```
https://images.unsplash.com/photo-1519741497674-611481863552?w=1920&h=1080&fit=crop
```
